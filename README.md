# YYKT Auto Player

广东工业大学在线学习平台（courses.gdut.edu.cn / 蕴瑜课堂）全自动播放浏览器插件。

自动播放课程视频、自动跳过PDF、跨课程自动续播，无需人工干预。

## 功能特性

- 自动播放课程视频，静音后台运行
- **视频真正播放完（ended）才跳转**，不再 90% 提前跳
- 视频结束后等待服务器进度上报确认，不足 90% 自动重播最后 6 秒触发心跳
- 自动跳过 PDF 等非视频资源
- 自动识别并跳过已完成的视频
- **跨课程自动续播**：一门课程结束后自动跳到下一门课程继续播放
- **课程首页全量扫描**：进入课程后先扫描所有视频完成状态，全部完成则直接跳过，部分完成则从第一个未完成视频开始
- 遇到测试题页面自动判定课程结束
- 自动抑制"网络异常"弹窗，避免页面卡死
- 播放卡顿自动恢复，严重时自动刷新页面
- 自动点击"按住验证"等防挂机检测
- 自动点击"继续播放""确定"等弹窗按钮
- 后台标签页防休眠（无声音频保活）
- 登录页检测与提醒
- **运行日志记录**：可在设置面板开启，自动保存到本地，7 天清理，便于排查问题
- **设置面板**：点击浏览器工具栏插件图标，可开关插件、开关日志、复制/查看/清空日志

## 安装方法

### Chrome / Edge 浏览器

1. 下载本仓库代码（或克隆到本地）
2. 打开浏览器扩展管理页面：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本插件所在文件夹
6. 安装完成，版本号显示为当前版本

## 使用说明

1. 登录 [courses.gdut.edu.cn](https://courses.gdut.edu.cn)
2. 进入「课程管理」页面，手动点击第一门课程进入
3. 在课程首页点击第一个视频开始播放
4. 之后插件全程自动运行，包括：
   - 自动播放每一集视频
   - 自动跳过 PDF 和已完成视频
   - 课程结束后自动切换到下一门课程

### 手动控制

- 点击页面顶部状态栏的 **YYKT** 标志可禁用/启用插件
- 禁用后插件停止所有自动操作，再次点击恢复

## 自动化流程

```
课程管理页(student.php)
    │  点击"点击进入该课程"
    ▼
课程首页(course/view.php?id=xxx)
    │  扫描所有视频完成状态
    ├─ 全部完成 → 标记课程完成 → 返回课程管理页选下一门
    └─ 部分完成 → 从第一个未完成视频开始
    │
    ▼
视频播放页(fsresource/view.php?id=xxx)
    │  自动播放，进度≥90%跳下一集
    │  自动跳过PDF、已完成视频
    │
    ├─ 遇到测试题(quiz/view.php) → 课程结束
    └─ 左侧栏最后一项播完 → 课程结束
    │
    ▼
标记课程完成 → 跳转课程管理页 → 循环以上流程
```

## 课程完成判定

满足以下任一条件即判定当前课程结束：

1. 页面跳转到测试题页面（URL 含 `mod/quiz`）
2. 课程左侧栏最后一个资源播放完毕

课程结束后自动将该课程 ID 记入 `localStorage`，后续不再重复学习。

## 进度判定逻辑

采用**视频结束事件 + 服务器进度双重确认**：

1. 监听视频 `ended` 事件，视频真正播放完才触发跳转
2. 视频结束后轮询服务器上报的播放进度（最多 18 秒）
3. 服务器进度 ≥ 90% 才跳下一个视频
4. 若结束后服务器进度仍不足 90%，自动重播最后 6 秒触发最终心跳上报（最多重试 1 次）
5. 播放过程中每 5 秒记录一次服务器进度与实际播放位置，便于排查

彻底避免了短视频因页面进度统计延迟导致的提前跳转问题。

## 注意事项

- 插件仅在 `courses.gdut.edu.cn` 域名下生效
- 登录态过期时插件会显示红色提示条，请手动登录后刷新页面
- 建议保持浏览器标签页在前台或启用标签页休眠豁免
- 清除课程记忆：在浏览器控制台执行 `localStorage.removeItem('__yykt_completed_courses')`
- 本插件仅供学习交流使用，请遵守学校相关规定

## 技术实现

- Manifest V3 浏览器扩展
- Content Script 注入页面，纯原生 JS 实现
- `inject.js` 在页面上下文屏蔽原生 `alert()`，防止网络异常弹窗卡死
- 无声振荡器（AudioContext）维持标签页音频活动状态，防止后台节流
- 课程完成状态存储于 `localStorage`，当前课程 ID 存储于 `sessionStorage`

## 文件结构

```
yykt-extension/
├── manifest.json    # 扩展配置（版本号、权限、匹配域名）
├── content.js       # 主逻辑（播放控制、跨课程跳转、状态检测、日志系统）
├── inject.js        # 页面上下文注入（屏蔽alert，防止网络异常弹窗卡死）
├── popup.html       # 设置面板 UI
├── popup.js         # 设置面板逻辑（开关、日志管理）
└── README.md        # 说明文档
```

## 版本日志

### v1.25
- 修复短视频播放完但服务器进度未达90%的问题：之前只重播最后6秒，对于进度只有70-80%的视频完全不够
- 新增**智能回退重看机制**：视频播放完后检查服务器进度，根据差距大小自动回退到合适位置继续播放
  - 进度 <75%：回退到25%位置（重看75%）
  - 进度 75-80%：回退到40%位置
  - 进度 80-85%：回退到55%位置
  - 进度 85-89%：回退到70%位置
- 回退重看期间实时监控进度，一旦达到90%立即跳下一个视频，无需等到视频再次播放完
- 最多重试3次，每次回退更多，确保进度达标
- 结束后轮询从6次（18秒）缩短为3次（9秒），加快响应速度
