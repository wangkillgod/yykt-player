## 功能

- **自动播放** — 进入视频页面自动静音播放
- **验证自动按住** — 检测"按住验证"按钮，自动模拟长按通过
- **进度感知切换** — 读取"我的播放进度"，达到 90% 自动跳下一集
- **PDF 自动跳过** — 播放到 PDF 等非视频课件时自动识别并跳过，持续跳到下一个视频再自动播放
- **网络异常自愈** — 在页面侧拦截"网络异常"原生弹窗（不再卡死）；自动点击"继续/重试/确定"类弹窗；播放卡住自动恢复，必要时自动刷新页面续播
- **后台防降速** — 无声音频保活，避免 Chrome 后台标签降速导致心跳超时
- **断点记忆** — 记住上次播放的视频（仅视频页），打开首页自动跳回
- **防挂起** — 自动恢复浏览器暂停的视频，防止休眠中断
- **状态栏** — 页面顶部显示播放状态和时间

## 安装

1. 下载本仓库 ZIP 或 `git clone`
2. Chrome 打开 `chrome://extensions/`
3. 右上角开启 **"开发者模式"**
4. 点 **"加载已解压的扩展程序"**
5. 选择 `yykt-extension` 文件夹
6. 打开 https://courses.gdut.edu.cn/ 即可

## 使用

安装后打开蕴瑜课堂视频页面，脚本自动生效：

- 顶部状态栏显示当前状态和时间
- 视频自动静音播放
- 出现"按住验证"时自动处理
- 看完一集自动跳下一集

刷新页面（F5）可强制回到记住的视频。

## 项目结构

```
yykt-extension/
├── manifest.json    # 扩展配置
└── content.js       # 核心脚本
```

## 技术细节

- Manifest V3
- 适配 courses.gdut.edu.cn 页面结构
- 含 iframe 内视频检测
- 使用 MediaSession API 保持播放活跃
- MutationObserver 监听页面动态变化

## 本版本相对原版的改动

> 基于原版 `v1.0` 修改，当前版本 `v1.3`。仅列出功能性差异。

| 问题 | 原版行为 | 本版本行为 |
|------|----------|-----------|
| PDF 课件 | 视频播完跳到 PDF 后脚本停摆，只能刷新或禁用插件 | 识别 PDF（`document.title` / 侧栏标题 / 内嵌 PDF 阅读器）后自动跳到下一个课件，连续 PDF 会一路跳过，直到落在视频课件并自动续播 |
| 网络异常弹窗 | 播放器弹出「继续」弹窗后永久卡住，需人工点击 | 自动点击「继续/重试/确定」类弹窗按钮；播放进度停滞时自动恢复，必要时自动刷新页面续播（带防循环保护） |
| 断点记忆 | 所有 `fsresource` 页面都会写入，可能记到 PDF 页 | 仅在确认找到视频后写入，避免恢复时又落到 PDF |
| 下一课件定位 | 用 URL 子串匹配当前条目，`id=17828` 会误匹配 `id=178282` | 改为按 `?id=` 严格相等匹配，并支持侧栏异步加载完成后再跳转 |
| 稳定性 | — | PDF 页只运行最小化跳过逻辑，避免与站点脚本互相干扰；状态栏新增点击「YYKT」紧急停用/启用开关 |
